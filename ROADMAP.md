# Roadmap de TrTravel

Ce document décrit la feuille de route pour les futures versions de TrTravel.

## Version Actuelle : v3.0.0

### Fonctionnalités Actuelles
- **Persistance des itinéraires** : Sauvegarde des modifications de la planification journalière
- **Gestion des erreurs** : Amélioration de la gestion des erreurs et des logs
- **Mise à jour des dépendances** : Toutes les dépendances mises à jour vers les dernières versions stables
- **Optimisations** : Meilleure performance et stabilité

## Prochaines Étapes

### v3.1.0 (Prochaine Version)

#### Objectifs
- **Synchronisation cloud** : Sauvegarde des données sur Firebase
- **Partage d'itinéraires** : Permettre aux utilisateurs de partager leurs itinéraires
- **Mode collaboration** : Planification de voyage en groupe
- **Notifications intelligentes** : Rappels basés sur la localisation

#### Tâches
- [ ] Intégrer Firebase pour la synchronisation cloud
- [ ] Implémenter la fonctionnalité de partage d'itinéraires
- [ ] Développer le mode collaboration pour la planification de voyage en groupe
- [ ] Ajouter des notifications intelligentes basées sur la localisation

#### Échéance
- **Date de début** : 2026-07-01
- **Date de fin** : 2026-07-31

### v3.2.0

#### Objectifs
- **Réalité augmentée** : Guide touristique en RA
- **Intégration des réservations** : Réservation d'hôtels et activités
- **Suivi des dépenses** : Budget de voyage avancé
- **Journal vocal** : Notes vocales pour le journal

#### Tâches
- [ ] Intégrer un SDK de réalité augmentée pour le guide touristique
- [ ] Développer un système de réservation d'hôtels et d'activités
- [ ] Implémenter un suivi des dépenses pour le budget de voyage
- [ ] Ajouter la fonctionnalité de journal vocal

#### Échéance
- **Date de début** : 2026-08-01
- **Date de fin** : 2026-08-31

### v4.0.0 (Version Majeure)

#### Objectifs
- **Refonte de l'UI** : Nouveau design moderne
- **Assistant IA** : Chatbot de voyage intelligent
- **Mode hors ligne avancé** : Toutes les fonctionnalités disponibles hors ligne
- **Multi-plateforme** : Version web et desktop

#### Tâches
- [ ] Refonte complète de l'interface utilisateur
- [ ] Développer un assistant IA pour aider les utilisateurs
- [ ] Améliorer le mode hors ligne pour inclure toutes les fonctionnalités
- [ ] Développer des versions web et desktop de l'application

#### Échéance
- **Date de début** : 2026-09-01
- **Date de fin** : 2026-09-30

## Backlog

### Idées Futures
- **Intégration des réseaux sociaux** : Partage sur les réseaux sociaux
- **Recommandations personnalisées** : Suggestions basées sur les préférences de l'utilisateur
- **Support multi-langues** : Ajout de nouvelles langues
- **Intégration des paiements** : Paiements en ligne pour les réservations
