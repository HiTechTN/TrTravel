# Roadmap de TrTravel

Ce document décrit la feuille de route pour les versions de TrTravel.

## Version Actuelle : v3.1.0

### Fonctionnalités Implémentées

#### v3.1.0 - Synchronisation Cloud et Collaboration
- **Synchronisation cloud** : Sauvegarde des données sur Firebase Firestore avec résolution de conflits
- **Partage d'itinéraires** : Liens de partage, QR codes, import d'itinéraires partagés
- **Mode collaboration** : Groupes de voyage, chat en temps réel, synchronisation des modifications
- **Notifications intelligentes** : Rappels géolocalisés, notifications basées sur le temps, suggestions contextuelles

#### v3.2.0 - Réalité Augmentée et Réservations
- **Guide touristique en RA** : Repérage des monuments via la caméra
- **Intégration des réservations** : Gestion des hôtels, activités et transports
- **Suivi des dépenses** : Budget avec catégories, graphiques et rapports
- **Journal vocal** : Enregistrement et transcription de notes vocales

#### v4.0.0 - Refonte et Intelligence Artificielle
- **Refonte de l'UI** : Composants modernes avec animations, verre dépoli, shimmer
- **Assistant IA** : Chatbot intelligent avec détection d'intention, suggestions contextuelles
- **Mode hors ligne avancé** : File d'attente de synchronisation, cache intelligent
- **Multi-plateforme** : Design responsive, adaptation web/desktop/mobile
